El juegoThe game遊戲內容

Las fuerzas oscuras avanzan hacia la torre de tu reino y hay que aguantar. Tocas a los enemigos para eliminarlos (algunos necesitan varios golpes). Cada seis derrotados se carga la energía de la torre, y con A la descargas contra todos. Si un solo enemigo llega a la torre, se acaba la partida.

Dark forces march on your kingdom's tower and you have to hold. You tap enemies to take them out (some need several hits). Every six kills charge the tower's energy, and A unleashes it on everyone. If a single enemy reaches the tower, it's game over.

黑暗勢力正朝王國的高塔進軍，你必須守住。點擊敵人就能消滅它們（有些要打好幾下）。每擊倒六個敵人就會為高塔充能，按下 A 就能對所有敵人釋放能量。只要有一個敵人碰到高塔，遊戲就結束。

Cinco niveles con dificultad creciente, pensado para partidas cortas.

Five levels of rising difficulty, built for short sessions.

五個難度遞增的關卡，適合短時間遊玩。

Programar para una Game BoyProgramming for a Game Boy為 Game Boy 寫程式

No hay motor ni lenguaje de alto nivel: todo está escrito en ensamblador Z80 (el dialecto de la CPU de la Game Boy). La consola tiene una pantalla de 160×144 píxeles, cuatro tonos y unos pocos KB de RAM de trabajo, así que cada sprite, cada byte de memoria y cada ciclo cuentan.

No engine, no high-level language: everything is written in Z80-style assembly for the Game Boy's CPU. The console has a 160×144 screen, four shades and a few KB of working RAM, so every sprite, byte and cycle counts.

沒有引擎，也沒有高階語言：全部都用 Game Boy 處理器的 Z80 風格組合語言撰寫。這台主機只有 160×144 的螢幕、四種色階和幾 KB 的工作記憶體，所以每個圖塊、每個位元組、每個時脈週期都很重要。

Lo hicimos entre tres personas del equipo PocketBoy: Javier Sainz-Pardo Tenza, Ángela Cabrera Ruiz y yo. El resultado es un .gb que corre en hardware real y en emulador.

Three of us built it as PocketBoy: Javier Sainz-Pardo Tenza, Ángela Cabrera Ruiz and me. The result is a .gb ROM that runs on real hardware and emulators.

我們三個人以 PocketBoy 的名義完成它：Javier Sainz-Pardo Tenza、Ángela Cabrera Ruiz 和我。成果是一個能在實機與模擬器上執行的 .gb ROM。

Mi papelMy role我的角色

Hice de project manager del equipo y de programador en las dos capas del juego: el gameplay (enemigos, oleadas, energía de la torre, niveles) y el funcionamiento interno que lo sostiene en la Game Boy.

I was the team's project manager and a programmer on both layers of the game: the gameplay (enemies, waves, tower energy, levels) and the internal systems that make it run on the Game Boy.

我是團隊的專案經理，也負責遊戲兩個層面的程式：遊戲玩法（敵人、波次、高塔能量、關卡），以及讓它能在 Game Boy 上運作的內部系統。

GBRetroDev'25

Tower Hero fue entrada oficial de GBRetroDev'25: Heroes of ASM 2, el concurso de desarrollo para Game Boy en ensamblador. Presentarlo implicaba cumplir las bases, cerrar una versión estable y publicarla.

Tower Hero was an official entry to GBRetroDev'25: Heroes of ASM 2, the Game Boy assembly game jam. Entering meant meeting the rules, locking a stable build and publishing it.

Tower Hero 是 GBRetroDev'25: Heroes of ASM 2 的正式參賽作品，這是一場 Game Boy 組合語言遊戲開發競賽。參賽代表要符合規則、定下穩定版本並正式發布。
